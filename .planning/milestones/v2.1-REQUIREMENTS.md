## v2.1 Requirements

### Self-Update (SELFUP)

- [x] **SELFUP-01**: When `@momidala/prefect` is installed globally, the `/prefect-update` Claude command file is automatically copied to `~/.claude/commands/` — ✓ Phase 2 (postinstall hook + handleInstallCommand)
- [x] **SELFUP-02**: When `@momidala/prefect` is uninstalled, the `/prefect-update` command file is automatically removed from `~/.claude/commands/` — ✓ Phase 2 (preuninstall hook + handleUninstallCommand)
- [x] **SELFUP-03**: User can run `/prefect-update` in Claude Code to update the prefect package to the latest version — ✓ Phase 2 (PREFECT_UPDATE_COMMAND_CONTENT template)
- [x] **SELFUP-04**: `/prefect-update` verifies and displays the new version number after updating — ✓ Phase 2 (node -e version extraction in template)
- [x] **SELFUP-05**: `/prefect-update` reminds the user to restart Claude Code after a successful update — ✓ Phase 2 ("Restart Claude Code to apply." in template)

### Checkpointing (CKPT)

- [x] **CKPT-01**: Prefect agents receive checkpoint instructions and write `checkpoint.md` after each file-modifying tool call — ✓ Phase 3 (AGENTS.md ## Checkpointing section, auto-loaded by OpenCode)
- [x] **CKPT-02**: `checkpoint.md` follows a defined schema (current task, last change, remaining steps, status) — ✓ Phase 3 (schema defined inline in AGENTS.md)
- [x] **CKPT-03**: When a prefect agent's context reaches ~80%, the agent writes `Handoff.md` and stops work — ✓ Phase 4 (instructed self-detection via "conversation feels crowded" trigger phrase)
- [x] **CKPT-04**: `Handoff.md` follows a defined schema (accomplished, current state, next steps, open questions) — ✓ Phase 3 (schema defined inline in AGENTS.md)
- [x] **CKPT-05**: Research spike resolves (a) whether OpenCode exposes context utilization %, and (b) how checkpoint instructions can be delivered — ✓ Phase 1 (AGENTS.md auto-load confirmed; context % NOT available; instructed self-detection as trigger)
