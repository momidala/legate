# Milestone v2.1: Developer Experience

**Status:** ✅ SHIPPED 2026-05-13
**Phases:** 1–4
**Total Plans:** 5

## Overview

v2.1 adds two independent developer experience improvements: a self-update mechanism so users can update prefect from within Claude Code, and automatic checkpointing so prefect agents (OpenCode agents spawned via `prefect_run`) write progress state and hand off cleanly when their context fills. A research spike ran first to establish both the context-utilization trigger and the delivery mechanism for agent instructions.

## Phases

### Phase 1: Context API Research

**Goal**: A concrete, documented decision on (a) how prefect agents receive checkpoint instructions, and (b) how/whether an OpenCode agent can detect ~80% context utilization to trigger Handoff.md
**Depends on**: Nothing (first phase)
**Requirements**: CKPT-05
**Plans**: 1 plan

Plans:
- [x] 01-01-PLAN.md — Audit findings doc for D-07/D-08 compliance; wire decisions into PROJECT.md and ROADMAP.md

**Details:**
- Confirmed AGENTS.md auto-load as the primary delivery vehicle for checkpoint instructions (no prefect code changes required)
- Confirmed instructed self-detection as the only viable Handoff.md trigger (OpenCode does NOT expose context % to agents)
- Confirmed session-level system prompt is NOT supported (silently ignored); per-run `system` field is the programmatic backup

**Plans**: 2 plans

## Milestone Summary

**Key Decisions:**

- AGENTS.md auto-load as delivery vehicle — no prefect code changes needed; works without GSD installed
- npm lifecycle hooks for command install — zero manual step for users
- Handoff trigger via instructed self-detection — OpenCode does not surface context % to agents; LLM self-judgment is the only available signal

**Issues Resolved:**

- CR-01: `isGlobal` false positive (path-segment check → `npm_config_global` env var)
- CR-02: Missing `preuninstall` hook (added to package.json)
- WR-01: TOCTOU race in `handleUninstallCommand` (→ `rmSync({force:true})`)
- WR-02: Silent skip of missing build artifacts in test helper (→ throw)
- WR-03: Fragile inline `node -e` script (→ `--input-type=commonjs`)
- IN-01: Missing trailing newline on AGENTS.md
- IN-02: No user feedback on direct `install-command` invocation

**Issues Deferred:**

- Optional: checkpoint.md committed automatically with a standard message
- Optional: Handoff.md `resume` command users can paste to pick up work
- Auto-check for updates on server start
- .gitignore entry for checkpoint.md (deferred per Phase 3 open question)

**Technical Debt Incurred:**

- `preuninstall` hook relies on `build/cli.js` existing at uninstall time; if the user deletes `build/` before uninstalling, the hook silently exits 0 (D-08 pattern)
